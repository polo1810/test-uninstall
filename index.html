🧪 Test de détection de désinstallation

Comment ça marche

1. L'utilisateur installe l'app via l'installeur Inno Setup
2. L'app crée un userId unique dans %APPDATA%\TestUninstall\user.txt
3. Quand l'utilisateur désinstalle, le hook [UninstallRun] lit l'userId et fait un POST vers /uninstalled?userId=XXX
4. Tu vois les pings dans les logs Netlify (onglet Functions → uninstalled → Logs)

Endpoint actif

L'endpoint qui reçoit les pings est :

https://VOTRE-SITE.netlify.app/.netlify/functions/uninstalled?userId=XXX

Tu peux le tester directement en cliquant : Simuler un ping

Voir les pings reçus

Va dans ton dashboard Netlify → Functions → uninstalled → Logs. Tu verras chaque désinstallation en temps réel.
